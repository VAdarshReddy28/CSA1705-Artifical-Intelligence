About This Project

This system demonstrates dynamic ambulance route optimization using A* and Greedy Best-First Search. It uses a sample road network, simulated traffic costs and road closures to study route selection and search performance.

A* Search

Uses g(n) + h(n), combining the cost already traveled with the estimated cost to the destination.

Greedy Best-First Search

Uses h(n), prioritizing the node estimated to be closest to the destination.
